# Posting results to the APDA Forum

At booking, select an existing tournament topic, ask MIT-Tab to create one, or choose **Not an APDA-sanctioned tournament**.

1. Once the varsity final and any novice final have decisions, open **Forum Post Results** in MIT-Tab.
2. Select **Post to APDA Forum** and confirm the list of dino judges. Cancel if a name is missing or incorrect, update the judges in MIT-Tab, and review again.
3. Select **View forum post** to open the results reply. The post will link to the tournament's tab cards once the rounds are saved in Black Rod.

Black Rod automatically receives the forum posting ID when VP Operations imports results from MIT-Tab. For manual results entry, expand **Forum posting ID** on the MIT-Tab page and copy the ID into the Black Rod results form.
